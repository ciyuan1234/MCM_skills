# 图表与表格规范示例

> 本文档给出获奖论文中最常见的图表呈现方式。AI 写论文时直接套用这些结构；
> 数值一律使用真实运行结果，不得编造。

## 1. 三线表（表格的唯一形式）

三线表 = 顶线 + 栏目线 + 底线，中间不画竖线。Markdown 中用 `---` 分隔行即可，
但**表格前必须有编号和题注，正文中必须引用**。

```
表1  各品类周平均销量统计
| 品类 | 平均销量/千克 | 标准差 | 变异系数 |
|:----:|:----:|:----:|:----:|
| 花叶类 | 245.31 | 68.42 | 0.279 |
| 水生根茎类 | 123.87 | 41.05 | 0.331 |
| 茄类 | 98.56 | 35.77 | 0.363 |
```

正文引用写法：`由表1可知，花叶类平均销量最高且波动最小……`
结论必须"从表中读出"，不允许只放表不解释。

## 2. 图（编号 + 题注 + 正文引用 + 图后结论）

```
图1  2016年全年蔬菜类商品日销量时序图
（此处插入图片）
```

图下方紧跟：
`由图1可看出，销量呈现明显的周内周期性波动，且节假日前后出现尖峰。`
**图后必须带一句结论**——这是获奖论文的固定动作。

常用图类型（按用途选）：
- 数据概况: 折线图、柱状图、箱线图
- 相关性: 散点图、相关系数热力图
- 聚类: 轮廓系数图、聚类散点图
- 预测: 拟合效果图（真实值 vs 预测值 + 残差图）
- 优化: 收敛曲线（遗传/模拟退火）、可行解分布针状图
- 空间: 地图 + 点位/热力

## 3. 公式（连续编号 (1)(2)(3)…，正文引用）

Markdown 中每行公式按顺序编号，正文用"由式(3)"引用。
LaTeX 用 `\begin{equation}` 自动编号。

## 4. 灵敏度/稳定性分析表

对关键参数做 ±5%、±10% 扰动，记录目标/结果变化：

```
表3  测线开角灵敏度分析
| 开角/° | 测线条数 | 总长/m | 漏测面积/m² | 相对基准变化 |
|:----:|:----:|:----:|:----:|:----:|
| 112（基准） | 34 | 125936 | 4380 | 0 |
| 118（+5%） | 33 | 121004 | 5120 | -3.9% |
| 106（-5%） | 35 | 131210 | 3905 | +4.2% |
```

结论句式：`结果表明，开角在 ±5% 内扰动时结果变化不超过 4%，模型稳定性良好；其中漏测面积对开角变化较为敏感。`

## 5. 误差分析表（每个模型求解后必配）

```
表4  问题一模型误差分析
| 指标 | 数值 |
|:----:|:----:|
| 平均绝对误差 MAE | 3.21 |
| 均方根误差 RMSE | 4.87 |
| 平均相对误差 MRE | 2.4% |
| R² | 0.976 |
```

## 6. 符号说明表（三列：符号 | 含义 | 单位）

```
| 符号 | 含义 | 单位 |
|:----:|:----:|:----:|
| $x_{it}$ | 第 $i$ 种单品第 $t$ 天进货量 | kg |
| $p_{it}$ | 第 $i$ 种单品第 $t$ 天定价 | 元/kg |
```

## 7. 流程图（每篇获奖论文至少一张）

建模思路图（问题分析节）或算法流程图（求解节）。手写 Markdown 可用 mermaid，
转 PDF 前渲染成图片。

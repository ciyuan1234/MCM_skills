# CUMCM 国赛规则（2026 年版基线）

## 基本信息

| 项目 | 规则 |
|---|---|
| 全称 | 全国大学生数学建模竞赛 |
| 时长 | 72 小时（每年 9 月中旬，通常周四 18:00 至周日 20:00） |
| 语言 | 中文 |
| 队伍 | 3 名同校本科生 + 1 名指导教师 |
| 题目 | A/B/C/D/E 五题，A 为连续型，B 为离散/优化，C 为数据分析 |

## 论文要求

| 项目 | 规则 |
|---|---|
| 格式 | PDF 或 Word，≤ 20 MB |
| 首页 | 摘要专用页（电子版第一页必须为摘要页） |
| 纸张 | A4，页边距 ≥ 2.5cm |
| 正文页数 | ≤ 30 页（不含摘要页、附录、参考文献、目录） |
| 字体 | 正文中文宋体/Times New Roman，英文 >= 12pt |
| 目录 | 不要目录 |
| 页脚 | 页码 |

## 摘要要求

- 字数：900-1200 字（获奖论文通常 700-1300）
- 五要素：①归类（模型类型）②思想（建模思路）③算法（具体方法）④特点（创新/稳健）⑤结果（逐问数值）
- 每个问题必须出现具体数值结果
- 关键词 3-6 个

## 参考文献格式

GB/T 7714-2015：
- 期刊：`作者. 题名[J]. 刊名, 年, 卷(期): 页码.`
- 图书：`作者. 书名[M]. 出版地: 出版社, 年.`
- 网页：`作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.`
- 只列真实读过的文献，≥ 5 条

## 图表规范

- 图题注在图下，表题注在表上
- 编号连续：图1, 图2, ...；表1, 表2, ...
- 三线表结构
- 正文必须引用每张图/表
- 图中结论要在正文中解读

## 提交要求

- 支撑材料：RAR/ZIP，≤ 20 MB
- 压缩包内不含承诺书/编号专用页
- 论文附录列出支撑材料文件清单
- 截止前完成上传

## 身份保护

- 正文/附录/代码/图表中不得出现学校名、队号、手机号、邮箱
- 唯一允许出现队号的位置：承诺书（不随电子版提交）

## AI 使用规范（2025 年新增）

- 标注 AI 生成内容：在使用处标注"以下内容由 AI 辅助生成"
- 引用 AI 工具：在参考文献中列出工具名称、模型/版本、开发者、使用日期
- 如使用 AI，支撑材料须包含 `AI工具使用详情.pdf`

## 常见题型与模型映射

| 题型 | 典型问题 | 推荐模型方向 |
|---|---|---|
| A 物理/连续 | 信号处理、物理建模 | 微分方程、傅里叶分析、插值 |
| B 工程/调度 | 排班、路径、调度 | 整数规划、遗传算法、模拟退火 |
| C 数据分析 | 预测、分类、聚类 | 回归、时序、随机森林、XGBoost |
| D 离散/优化 | 图论、组合优化 | 动态规划、网络流、贪心 |
| E 经营/管理 | 定价、库存、选址 | 线性规划、排队论、博弈论 |

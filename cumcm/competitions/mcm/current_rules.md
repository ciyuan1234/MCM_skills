# MCM/ICM 美赛规则（2027 年版基线）

## 基本信息

| 项目 | 规则 |
|---|---|
| 全称 | Mathematical Contest in Modeling / Interdisciplinary Contest in Modeling |
| 时长 | 96 小时（通常 2 月初，周四 5:00pm EST 至周一 8:00pm EST） |
| 语言 | 英文 |
| 队伍 | 3 名本科生，同一所学校 |
| 题目 | MCM: A/B/C；ICM: D/E/F（共 6 题） |
| 组织 | COMAP（美国数学及其应用联合会） |

## 论文要求

| 项目 | 规则 |
|---|---|
| 格式 | 一个 PDF 文件 |
| 总页数 | ≤ 25 页（含摘要、正文、参考文献、目录、附录、代码） |
| 首页 | Summary Sheet（摘要页，团队控制号在页眉） |
| 字体 | >= 12pt |
| 页眉 | Team Control Number + page number |

## Summary Sheet（摘要页）要求

- 第一页必须是 Summary Sheet
- 页眉含 Team Control Number
- 摘要应清晰概括方法、结果和结论
- 是评委首先阅读的内容，极其重要

## 论文结构（推荐）

1. Summary Sheet（第一页）
2. Introduction（≥ 5 条引用）
3. Assumptions and Justifications
4. Notation（符号说明）
5. Model Development（含 algorithm2e 伪代码）
6. Sensitivity Analysis（≥ 2 参数，±10%/±20%/±50%）
7. Strengths and Weaknesses
8. Conclusions
9. References（APA 或编号格式，≥ 8 条，≥ 3 条英文期刊）
10. Appendices

## 实用文档（Memo/Letter）

- 部分题目要求写给特定受众的 memo/letter（如 1 页短文）
- 需检测题目中的 "write a memo"、"letter to" 等关键词
- 格式：收件人、发件人、日期、主题行

## 提交要求

- 通过 COMAP 官网在线提交
- 一个 PDF 文件
- 团队控制号必须在页眉
- 不得在正文中出现学校名、指导教师名

## AI 使用规范

- 提交后附 "Report on Use of AI" 部分（不计入 25 页限制）
- 内容：使用的 AI 工具、使用方式、大致比例
- 正文中使用 AI 生成内容需标注

## 评分标准

| 维度 | 权重 | 说明 |
|---|---|---|
| Summary | 高 | 方法、结果、结论的清晰度 |
| Assumptions | 中 | 合理性、针对性 |
| Model | 高 | 必要性、创新性、与问题匹配 |
| Sensitivity | 中 | ≥ 2 参数，定量分析 |
| Writing | 高 | 清晰、简洁、学术英语 |
| References | 低 | 真实、充分、格式规范 |

## 常见题型

| 类型 | 典型问题 | 推荐方向 |
|---|---|---|
| A (Continuous) | 传播、扩散、动力系统 | ODE/PDE、数值模拟 |
| B (Discrete) | 路径、调度、网络 | 图论、整数规划、启发式 |
| C (Data) | 预测、分类、评估 | 回归、时序、机器学习 |
| D (Network) | 流量、韧性、级联失效 | 网络科学、图论 |
| E (DE) | 生态、环境、可持续 | 微分方程、系统动力学 |
| F (Policy) | 政策评估、博弈 | 博弈论、多准则决策 |

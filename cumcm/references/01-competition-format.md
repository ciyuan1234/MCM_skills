# 01 · 全国大学生数学建模竞赛论文格式规范

> 依据：《全国大学生数学建模竞赛论文格式规范》（官方发布版，共 13 条，见文末附录）。
> 每年开赛前 1 小时先到官网（http://www.mcm.edu.cn）下载当年《格式规范》核对，
> 以当年文件为准。本文按官方 13 条逐条整理，并标注检查器对应项。

## 1. 论文结构（按页码顺序）

| 页码 | 内容 | 说明 |
|---|---|---|
| 第一页 | 承诺书（纸质版） | 电子版论文**不含**承诺书/编号专用页 |
| 第二页 | 编号专用页（纸质版） | 赛区填写 |
| 第三页 | **论文题目 + 摘要 + 关键词** | 摘要独占一页且不超一页；页码从此页起 |
| 第四页起 | 正文（**不要目录，≤30 页**） | **篇幅硬标准 20-25 页**（下限 20，format-check 硬检查；获奖论文实测 25-35 页） |
| 正文末 | 参考文献 | GB/T 7714，正文引用处标 [x] |
| 附录 | 文件列表 + 完整可运行代码 | 页数不限，与正文装订；无程序须声明 |

## 2. 摘要要求

- 摘要内容应包括：问题的简述、所用的模型和方法、主要结果（**每个问题都要有具体数值结果**）
- 官方 HARD：摘要（含标题和关键词）不超一页；字数 700-1300 字（获奖论文常见区间）
- 关键词 3-6 个，用方法名词
- 摘要不能出现"本文"之外的套话，不能用"大概""可能"等模糊词
- **摘要是评委评分的第一来源，必须最后打磨**

## 3. 正文排版要求

- 页面：A4；正文小四号宋体；标题黑体；**页边距上下左右 ≥ 2.5cm**（官方 HARD）
- 公式：公式编辑器输入，居中，编号右对齐，连续编号 (1)(2)(3)…
- 编译路线（推荐）：`md2tex.py`（md→tex）→ xelatex 编译，公式/表格/中文排版质量最优；
  无 xelatex 时回退 Word 路线（md2docx.py + Word COM）
- 图表：每张图/表必须有编号和题注（"图1 xxx"在**图下**、"表1 xxx"在**表上**），正文中必须引用（"如图2所示""由表1可知"）
- 表格用三线表（顶线/表头线/底线，无竖线）
- **页码从摘要页起连续编号**，位于页脚中部（官方 HARD）；电子版第一页必须为摘要专用页
- 正文引用参考文献处必须标注 [x]（官方 HARD），覆盖全部或主要文献
- **正文页数**：官方 HARD ≤30 页（不含附录）；建议目标 ≤25 页（获奖论文体量）
- **身份信息**：摘要页/正文/附录任何地方不得出现学校、队号、姓名、手机号等（官方 HARD）

## 4. 参考文献格式（GB/T 7714）

| 类型 | 格式 |
|---|---|
| 书籍 | 作者. 书名[M]. 出版地: 出版社, 出版年. |
| 期刊 | 作者. 论文名[J]. 杂志名, 卷(期): 起止页码, 出版年. |
| 网页 | 作者. 标题[EB/OL]. 网址, 访问时间. |
| 论文集 | 作者. 题目[C]//编者. 论文集名. 出版地: 出版社, 出版年: 页码. |

示例：
```
[1] 姜启源, 谢金星, 叶俊. 数学模型（第五版）[M]. 北京: 高等教育出版社, 2018.
[2] 司守奎, 孙玺菁. 数学建模算法与应用（第二版）[M]. 北京: 国防工业出版社, 2015.
[3] 国家统计局. 中国统计年鉴 2023[EB/OL]. https://www.stats.gov.cn/, 2026-09-07.
```

**引用他人成果必须在正文引用处与参考文献中均明确列出**，否则按抄袭处理。

## 5. 提交物（两个电子文件）

### 5.1 参赛论文（电子版）
- 单个文件：PDF 或 Word 均可（建议 PDF），**≤20MB，不要压缩**
- **第一页必须为摘要专用页**（不含承诺书/编号专用页）
- 内容与纸质版一致（含附录；附录与正文装订在同一文件内）

### 5.2 支撑材料（一个压缩包）
- 至少包含：**全部可运行源程序**、**自主查阅使用的数据资料**（赛题提供的原始数据除外，如统计年鉴、网上搜集数据）、较大篇幅中间结果的图表
- 使用 WinRAR 压缩为**单个 RAR/ZIP，≤20MB**
- **文件列表须放入论文附录**（"支撑材料文件列表"）
- 不得含承诺书/编号专用页；**所有文件不得含身份信息**
- 确实没有支撑材料 → 在附录注明"本论文没有支撑材料"，可不提供压缩包
- 支撑材料与论文内容不符 → 可取消评奖资格

### 5.3 附录豁免条款
- 确实没有用到程序 → 在附录注明"本论文没有用到程序"
- 确实没有支撑材料 → 在附录注明"本论文没有支撑材料"

### 5.4 工作区落地
- 代码：`2_代码`（全部可运行源程序，含数据读取与结果写出）
- 支撑材料：`5_支撑材料`（自主查阅数据、中间结果图表等）
- 打包：`cumcm\scripts\package.ps1 -WorkDir <工作区>`（自动校验大小/承诺书/身份信息）
- 当年要求的其他文件（如 result.xlsx 等按题目要求命名）

## 6. 查重

- 论文提交后系统统一查重（知网等），**重复率过高取消评奖资格**
- 控制手段：摘要/正文用自己的话重写；图表用自己的数据重画；代码注明出处
- 查重前务必检查：直接从网上复制的段落、队友间共用文本

## 7. 诚信红线

- 不得抄袭他人论文或往年优秀论文
- 不得在网上讨论赛题（比赛期间禁止外联讨论）
- 所有数据结果必须真实来自自己的计算

## 附录：官方规范全文（供逐条核对）

一、纸质版论文格式规范

第一条 论文用白色A4纸打印(单面、双面均可)；上下左右各留出至少2.5厘米的页边距；从左侧装订。

第二条 论文第一页为承诺书，第二页为编号专用页，具体内容见相关专用页。

第三条 论文第三页为摘要专用页。摘要内容（含标题和关键词，无需翻译成英文）原则上不能超过一页；论文从此页开始编写页码，页码位于页脚中部，用阿拉伯数字从"1"开始连续编号。

第四条 论文从第四页开始是正文内容（不要目录，不超过30页）；正文之后是论文附录（页数不限），附录内容必须打印并与正文装订在一起提交。

第五条 论文附录内容应包括支撑材料的文件列表，建模所用到的全部完整、可运行的源程序代码（含EXCEL、SPSS等软件的交互命令）等。如果缺少必要的源程序、程序不能运行或运行结果与论文不符，都可能会被取消评奖资格。如果确实没有用到程序，应在论文附录中明确说明"本论文没有用到程序"。

第六条 论文摘要专用页、正文和附录中任何地方都不能有显示参赛者身份和所在学校及赛区的信息。

第七条 所有引用他人或公开资料(包括网上资料)的成果必须按照科技论文的规范列出参考文献，并在正文引用处予以标注。

第八条 本规范中未作规定的，如论文的字号、字体、行距、颜色等不做统一要求。在不违反本规范的前提下，各赛区可以对论文做相应的要求。

二、电子版论文格式规范

第九条 参赛队应按照《全国大学生数学建模竞赛报名和参赛须知》的要求提交参赛论文和支撑材料两个电子文件。

第十条 参赛论文电子版内容必须与纸质版内容及格式（包括附录）完全一致；必须是一个单独的文件，文件格式为PDF或者Word格式之一（建议使用PDF格式）；文件大小不超过20MB。注意参赛论文电子版文件不要压缩，承诺书和编号专用页不要放在电子版论文中，即电子版论文的第一页必须为摘要专用页。

第十一条 支撑材料内容包括用于支撑模型、结果、结论的所有必要材料，至少应包含建模所用到的所有可运行源程序、自主查阅使用的数据资料（赛题中提供的原始数据除外）、较大篇幅中间结果的图表等。将所有支撑材料文件使用WinRAR软件压缩在一个文件中（后缀为RAR或ZIP，大小不超过20MB）。支撑材料的文件列表应放入论文附录；如果确实没有需要提供的支撑材料，可以不提供支撑材料文件，并在论文附录中注明"本论文没有支撑材料"。如果支撑材料文件与论文内容不相符，该论文可能会被取消评奖资格。注意竞赛的承诺书和编号专用页不要放在支撑材料中，所有文件中不能有显示参赛者身份和所在学校及赛区的信息。

三、本规范的实施与解释

第十二条 本规范自发布之日起试行，以前的规范与本规范不相符的，以本规范为准。不符合本规范的论文将被视为违反竞赛规则，可能被取消评奖资格。

第十三条 本规范的解释权属于全国大学生数学建模竞赛组委会

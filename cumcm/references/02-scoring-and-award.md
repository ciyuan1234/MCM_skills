# 02 · 评阅标准与获奖论文解剖

> 来源：评阅原则文件、历年经验谈、2021-2023 年五篇国一论文的实证拆解
> （2023 A092 定日镜场、2023 B226 多波束测线、2023 C050 蔬菜定价、
>  2023 E032 黄河水沙、2022 A001 波浪能、2021 A028 FAST 反射面）。

## 1. 评阅原则（官方四原则）

1. 假设的合理性
2. 建模的创造性
3. 结果的合理性
4. 表述的清晰程度

评委检查答卷主要把"三关"：
- 第一关：模型的正确性、合理性与创新性
- 第二关：结果的正确性与合理性
- 第三关：文字表述清晰、分析精辟、摘要精彩

## 2. 摘要五要素（摘要必须包含）

1. 模型的数学归类（在数学上属于什么类型：线性规划/时间序列/图论…）
2. 建模的思想（建模思路的核心）
3. 算法思想（求解算法的关键：如遗传算法+模拟退火互验）
4. 建模特点（模型特色，如"双算法互验""误差小于 3%"）
5. 主要结果（**回答题目全部问题，每个问题给出具体数值**）

## 3. 获奖论文七章结构（实证）

| 章节 | 内容要点 |
|---|---|
| 一、问题重述 | 1.1 背景（重述而非照抄）+ 1.2 问题重述（数学化改写） |
| 二、问题分析 | 逐问分析 + **总体思路流程图**（必配） |
| 三、模型假设 | 4-6 条编号假设，每条有事实依据（如"距离越短影响越大"） |
| 四、符号说明 | 三列表：符号 / 含义 / 单位 |
| 五、模型建立与求解 | 按 5.1/5.2… 分问题；每问内"数据预处理→模型建立→求解→结果分析→检验"五连 |
| 六、模型的评价、改进与推广 | 优点 2-3 条 / 缺点 2-3 条 / 改进与推广 |
| 七、参考文献 | GB/T 7714，5-10 条 |
| 附录 | 代码清单（文件名+功能+运行环境）+ 核心代码全文 |

## 4. 获奖论文的"亮点"写法（评委加分的套路）

1. **数字化摘要**：摘要中每问都给具体最优值（如"34 条测线、总长 125936m、漏测 3.48%"），让评委一眼看到工作量
2. **双算法互验**：主算法 + 独立算法互相验证（贪心 vs 模拟退火"两种方法误差很小"；随机生成 100 组可行解画针状图对比，给出"优化率 17.11%"）
3. **灵敏度分析专节**：关键参数 ±5% ±10% 扰动 + 对比图 + 定性结论（"测线位置对开角变化较为敏感"）
4. **每问都带模型检验**：误差分析表（MAE/RMSE/MRE/R²），检验指标齐全
5. **方法堆叠有层次**：描述统计→相关系数（Spearman/Pearson）→聚类（K-means++）→预测→优化，层层递进
6. **数据预处理"数据侧写"专节**：数据分析题（C/E 题）的固定动作
7. **附录工程化**：代码文件清单 + 功能注释 + 分文件组织，体现可复现性
8. **每图后一句结论**："由图X可看出……"（获奖论文的固定动作）

## 5. 常见扣分点（避开即赢）

- 摘要没数字、没逐问覆盖 → 直接降档
- 模型堆砌不解释（列 5 个模型却不用）→ 扣建模分
- 假设没依据（乱假设）→ 评阅第一原则就挂了
- 缺灵敏度/稳定性分析 → 结果合理性存疑
- 图表无编号题注、正文不引用 → 表述清晰度扣分
- 参考文献格式混乱 / 网上抄的参考文献 → 诚信扣分
- 结果与实际数量级不符（没跑过程序）→ 严重扣分
- 附录无代码 / 代码跑不了 → 支撑材料不合格

## 6. 数据分析题（C/E）vs 物理题（A/B）的差异

**A/B 题（物理机理型）**：
- 主线：公式推导（几何/物理）→ 参数计算 → 优化 → 灵敏度
- 不需要数据预处理、相关性检验章节
- 摘要侧重"模型机理推导 + 最终数值"

**C/E 题（数据分析型）**：
- 主线：数据清洗 → 探索性分析 → 相关性/规律挖掘 → 预测/分类 → 优化决策
- 必须有"数据侧写/数据预处理"独立章节
- 必须有统计检验（回归系数置信区间、F 检验、残差分析）
- 摘要强调量化分析结论与预测检验指标

## 5. 模型选择决策逻辑（AI 按此顺序推荐）

1. **问题分类**：先判断题型（A-E）和问题性质（优化/预测/评价/分类/模拟）
2. **候选模型**：从映射表中列出 2-3 个候选，评估输入数据可得性
3. **简单优先**：能用初等方法解决就不用高级方法（评阅原则）；
   先做简单基线模型（如线性回归/均值预测），再考虑复杂模型
4. **复杂兜底**：简单模型效果差（误差大/不满足约束）时升级：
   线性→非线性、静态→动态、确定性→随机
5. **每个模型必须能解释**：选模型必须说明"为什么是这个模型、假设是什么、在回答题目哪个问题"
6. **结果必须经过检验**：误差指标（MAE/RMSE/MRE/R²）+ 对比实验

## 5.1 创新性设计（v1.4.0 起必做——反"经验模板化"）

> 背景：CUMCM 评阅中"模型与常见解法雷同"是失分主因。
> 守则：**先用标准方法拿到可复现的基线答案，再在"问题特异性"处做差异化，
> 绝不为创新而创新（不能牺牲可解释性与正确性）。**

### 第一步：问题特异性分析（每题必答 3 问）
1. 本题的**特有约束/机理/数据特征**是什么？（例：2021C 单价与消耗系数方向相反、2024C 稀疏 IP 矩阵与随机鲁棒性）
2. 标准教科书解法在本题的**盲区**是什么？（例：普通 LP 无法表达"多A少C"的结构偏好；普通回归无法处理稀疏计数矩阵）
3. 我们的**差异化建模点**落在哪一环？（特征工程 / 目标函数 / 约束 / 算法 / 检验）

### 第二步：第二梯队方法库（在基线模型不满足时升级，优先组合而非替换）
| 场景 | 第一梯队（常规） | 第二梯队（差异化，本地资料可查） |
|---|---|---|
| 不确定性数据 | 均值/期望 | 鲁棒优化（盒式/椭球）、随机规划（场景抽样）、CVaR |
| 相关性分析 | 皮尔逊 | Spearman 秩相关、Copula、偏相关 |
| 多目标 | 权重加权 | 帕累托前沿（NSGA-II）、ε-约束法、目标规划 |
| 启发式求解 | 贪心/模拟退火 | 自适应大邻域搜索、遗传+局部搜索混合 |
| 机理数据并存 | 纯数据驱动 | 机理-数据融合（残差修正、参数标定） |
| 时间序列 | ARIMA | 动态线性模型、状态空间/Kalman、变点检测 |
| 分类评价 | 熵权+TOPSIS | 灰关联、秩和比法（RSR）、双基准 TOPSIS |

### 第三步：组合创新三模式（从第二梯队选 1-2 个与基线组合）
1. **目标函数改造**：加业务权重/惩罚项/鲁棒项（如 2021C 类别权重、2024C 随机需求场景）
2. **算法混合**：精确+启发式（LP 定界 + 启发式搜索）、双算法互验
3. **检验升级**：灵敏度 + 场景模拟 + 置信区间，三重证据链

### 第四步：三问自检（论文写作前）
- [ ] "这个模型换成 2021 年的获奖论文套路也能写出来吗？"——能，则差异化不足
- [ ] "创新点是否可复现、有数值证据？"——必须在正文给出对比表/图
- [ ] "创新点是否牺牲了可解释性？"——必须仍能逐条解释模型行为
- 产出：论文"问题分析 → 创新点定位"小节（模板 §2.6），每问 1-2 句"本题特异性 + 我们的差异化"

## 5.3 差异性自检（查库之后、定稿之前）

- [ ] **至少 2 处与获奖做法不同**：对照模式库速查表，逐问写出"本题做法的差异化维度"（数据口径/约束表达/目标设定/算法/检验任选），<2 处视为照搬
- [ ] **降维/简化有依据**：借鉴获奖手法的"简化思想"时必须给出适用性论证（为什么本题可以这样简化），禁止直接搬近似公式
- [ ] **方法链长度匹配**：国赛评审对复杂方法链宽容，但每个复杂方法必须：数据支撑 + 与简单基线对比 + 可解释
- [ ] **评阅四要素自评**：假设合理性 / 建模创造性 / 结果合理性 / 表述清晰度，各打 1-5 分，任何一项 <3 必须补强

## 6. 灵敏度与稳定性分析清单

- 参数扰动：对关键参数做 ±5%、±10% 扰动，记录目标值/结果变化
- 双算法互验：主算法结果用另一个独立算法验证（贪心↔模拟退火、遗传↔PSO）
- 随机性检验：随机初始化多次运行（100 组可行解），统计最优值分布
- 敏感性排序：哪个参数变化对结果影响最大，给出定性结论
- 边界测试：极端参数下模型是否合理（验证假设边界）

### 1.4 已知缺陷与修复版（重点：AI 必须使用修复版）

**① 灰色关联分析代码**（7\灰色关联分析代码.txt）
- 缺陷：`n` 未定义；`max`/`min` 作变量名覆盖内置函数
- 修复要点：`n = size(x,2)`（或按数据维度显式赋值）；变量改名 `mymax`/`mymin`

**② SVM分类器代码**（7\SVM分类器代码.txt）
- 缺陷：第 44 行 `a>=C && a<=0` 恒假；`Wold=0` 首次除法 Inf；R2016b+ 局部函数 `k(x1,x2)` 必须移到文件末尾或拆分为独立函数
- 修复要点：改写 KKT 检查条件为 `a(i) > 0 && a(i) < C`；初始化 `Wold = eps` 或先更新再比较；数据文件需自行构造（两分类）

**③ 主成分分析代码**（7\主成分分析代码.txt）
- 缺陷：脚本含 `>>` 命令行提示符
- 修复要点：删除所有 `>>` 前缀再运行

**④ 排队论 p_s 公式**（7\排队论算法代码.txt）
- 缺陷：p_s 为手写展开式，仅适用于 s=5 且公式可疑
- 修复要点：改用 M/M/s 解析公式（Erlang C 公式）或直接调用工具箱函数

**⑤ 灰色预测代码**
- 缺陷：循环内缺分号导致打印中间值（无害）
- 修复要点：补齐分号，输出更干净

### 1.5 编码警告（非常重要）

- 目录 7 的全部 .txt 为 **GBK/ANSI 编码**，UTF-8 工具读取中文注释会乱码
- MATLAB 中文版直接打开正常；**不要用编辑器转换编码后回存**（会破坏文件）
- AI 读取这些文件时若乱码，先用 `Get-Content -Encoding Default`（PowerShell）读
- 建议做法：AI 参考其算法逻辑，在 `2_代码\` 中**重写干净的 UTF-8 版本**，不直接复制乱码文件

## 3. MATLAB 还是 Python？（选择规则）

| 情况 | 选择 |
|---|---|
| 题目数据是 xlsx/csv，要做统计检验、聚类、预测 | **Python**（pandas+sklearn 生态碾压） |
| 队伍习惯 MATLAB、题目涉及图像处理 | **MATLAB**（imread 系列现成） |
| 需要解线性/整数规划、调 LINGO | MATLAB/LINGO（目录7 有现成代码） |
| 神经网络/深度学习 | Python（MATLAB 旧版 newff 已过时） |
| 快速验证一个算法思想 | 先用 Python 写原型，再决定正式版本 |

# 05 · 摘要与论文写作指南

## 1. 摘要写作（最重要，占评分权重最高）

### 1.1 五要素（一个不能少）

1. **数学归类**：在数学上属于哪类问题（线性规划/时间序列/图论/微分方程…）
2. **建模思想**：建模思路的核心（如"将销量分解为季节+趋势+随机三部分"）
3. **算法思想**：求解算法关键（如"遗传算法求解，模拟退火互验"）
4. **建模特点**：模型特色（"双算法互验，误差小于 3%"）
5. **主要结果**：回答题目全部问题，**每个问题给出具体数值**

### 1.2 结构模板（900-1200 字）

```
[第1段] 一句话点题：本文针对 X 问题，建立 Y 模型/给出 Z 方法。
[第2段] 针对问题一，建立……模型（……），采用……算法求解，得到……（具体数值）。
[第3段] 针对问题二，……
[第4段] 针对问题三，……
[第5段] 针对问题四，……
[第6段] 对模型进行灵敏度分析与检验，结果表明……；模型可推广至……。
```

### 1.3 禁忌

- 不能有"大概""可能""也许"
- 每个数值必须来自真实运行结果，不得编造
- 不能只写"用线性规划求解"这种空话，必须写"得到最小成本 12345 元"
- 摘要要在论文写完后再精修（至少花 2 小时），修改后重新检查数值一致性

### 1.4 摘要示例（结构示范，数值为占位）

> 本文针对商超蔬菜定价与补货问题，综合运用统计分析与优化建模方法，建立了需求预测与利润最大化模型。
> 针对问题一，对 6 大品类 93 种单品的历史销量进行数据侧写，采用 K-means++ 聚类将品类划分为四档，
> 并用 Spearman 相关系数分析得到"花叶类与茄类销量显著负相关"的结论。
> 针对问题二，建立价格-销量回归模型，求解得到销量弹性为 -0.62，据此给出各单品最优定价，
> 使日毛利提升 8.4%。
> 针对问题三，基于 ARIMA 模型预测未来一周销量，平均相对误差 4.1%。
> 针对问题四，建立带损耗率约束的线性规划模型，给出周补货与定价方案，预计周利润 2.3 万元，
> 较现有方案提高 12.6%。
> 最后对模型进行灵敏度分析，结果表明方案对损耗率较敏感，其余参数稳定；模型可推广至零售连锁行业。

## 2. 论文标题拟法

- 可用题目原题（如《定日镜场的优化设计》）
- 可微改更"研究化"：《某商超蔬菜类商品动态定价与补货决策研究》《"FAST"主动反射面调节模型》
- 不要用太文艺的标题，要直白点出研究对象+方法

## 3. 七章写作要点

### 一、问题重述
- 背景用自己的话重述 1-2 段（可引用题目数据来源），不照抄原文
- 问题重述：把题目要求改写为清晰的数学问题，逐条列出

### 二、问题分析
- 总体思路：先讲技术路线（数据预处理→相关性→建模→求解→检验→优化）
- **必须配一张总体思路流程图**
- 逐问分析难点与拟用方法

### 三、模型假设
- 4-6 条，编号列表
- 每条必须有事实依据（如"由数据观察，周销量无显著趋势，故假设需求平稳"）
- 假设不合理的直接挂评阅第一原则

### 四、符号说明
- 三列表：符号 / 含义 / 单位，全表列出主要变量

### 五、模型建立与求解（主体，篇幅最大）
- 按 5.1/5.2/5.3/5.4 分问题
- 每问内部固定流程：
  1. **问题分析**（该问难点 + 方法选择理由）
  2. **模型建立**（推导 + 公式连续编号 (1)(2)(3)…）
  3. **模型求解**（算法、参数设置、运行环境）
  4. **结果分析**（结果表 + 图 + 误差分析）
  5. **模型检验**（误差指标、对比实验）
- 数据题必须加**数据预处理/数据侧写**小节（缺失值、异常值、去重、分组聚合）
- 每张图后必须有一句"由图X可看出……"的结论

### 六、模型的评价、改进与推广
- 优点 2-3 条（真实、具体，如"双算法互验，结果可靠"）
- 缺点 2-3 条（诚实，如"未考虑天气因素"）
- 改进与推广（模型可扩展到哪些场景）

### 七、参考文献
- GB/T 7714 格式（见 01-competition-format.md），5-10 条
- 必须是真读过的文献，别抄网上乱写

### 附录
- 代码清单：文件名 / 功能 / 运行环境 列表 + 核心代码全文
- 支撑材料中的代码要与论文附录对应

## 4. 图表规范

- 图：编号 + 题注（"图1 xxx"），正文引用（"如图1所示"），图后带结论
- 表：三线表，编号 + 题注（"表1 xxx"），正文引用（"由表1可知"）
- 结果保留 4 位小数
- 详细示例见 `assets/result-table-samples.md`

## 5. 数据分析题 vs 物理题（写作差异速记）

- **物理题（A/B）**：重公式推导和最终数值，无数据预处理章节
- **数据题（C/E）**：必须有数据侧写、相关性检验、预测/分类比选、统计检验

# 05 · 摘要与论文写作指南

## 1. 摘要写作（最重要，占评分权重最高）

### 1.1 五要素（一个不能少）

1. **数学归类**：在数学上属于哪类问题（线性规划/时间序列/图论/微分方程…）
2. **建模思想**：建模思路的核心（如"将销量分解为季节+趋势+随机三部分"）
3. **算法思想**：求解算法关键（如"遗传算法求解，模拟退火互验"）
4. **建模特点**：模型特色（"双算法互验，误差小于 3%"）
5. **主要结果**：回答题目全部问题，**每个问题给出具体数值**

### 1.2 结构模板（900-1200 字）

```
[第1段] 一句话点题：本文针对 X 问题，建立 Y 模型/给出 Z 方法。
[第2段] 针对问题一，建立……模型（……），采用……算法求解，得到……（具体数值）。
[第3段] 针对问题二，……
[第4段] 针对问题三，……
[第5段] 针对问题四，……
[第6段] 对模型进行灵敏度分析与检验，结果表明……；模型可推广至……。
```

### 1.3 禁忌

- 不能有"大概""可能""也许"
- 每个数值必须来自真实运行结果，不得编造
- 不能只写"用线性规划求解"这种空话，必须写"得到最小成本 12345 元"
- 摘要在论文写完后**最后写**（见 1.5 最后写原则）

### 1.4 摘要示例（结构示范，数值为占位）

> 本文针对商超蔬菜定价与补货问题，综合运用统计分析与优化建模方法，建立了需求预测与利润最大化模型。
> 针对问题一，对 6 大品类 93 种单品的历史销量进行数据侧写，采用 K-means++ 聚类将品类划分为四档，
> 并用 Spearman 相关系数分析得到"花叶类与茄类销量显著负相关"的结论。
> 针对问题二，建立价格-销量回归模型，求解得到销量弹性为 -0.62，据此给出各单品最优定价，
> 使日毛利提升 8.4%。
> 针对问题三，基于 ARIMA 模型预测未来一周销量，平均相对误差 4.1%。
> 针对问题四，建立带损耗率约束的线性规划模型，给出周补货与定价方案，预计周利润 2.3 万元，
> 较现有方案提高 12.6%。
> 最后对模型进行灵敏度分析，结果表明方案对损耗率较敏感，其余参数稳定；模型可推广至零售连锁行业。

### 1.5 90 秒规则（评委视角）

评委前 90 秒决定论文印象（~5 分钟/篇，前 90 秒看摘要页）：

```
第 1 秒：一句话命名问题（不是复述题目，是用自己的话定范围）
  ✗ "蔬菜定价与补货"（复述题目）
  ✓ "生鲜商超蔬菜'当日未售出隔日即报废'的短保特性下的动态定价与补货决策"（定范围）

第 5 秒：一句话命名方法（具体技术名，不是泛称）
  ✗ "建立了数学模型"（空话）
  ✓ "对数线性回归 + 模拟退火 + 乘法季节分解"（具体方法）

第 15 秒：数值答案（具体数字 + 单位 + 条件）
  ✗ "提高了利润"（无数字）
  ✓ "日毛利提升 8.4%，预计周利润 2.3 万元"（有数字、有单位）

第 30 秒：3-5 条建议（利益相关者该做什么，排序）
  ✓ "①花叶类日补货 140kg ②损耗率>5% 的品类降价 3-5% ③增设茄类促销"
```

**获奖摘要特征（基于59篇一等奖论文分析）：**
- 字数 p25/p50/p75 = 748/992/1146 字
- 数值密度：p50 = 50 处数值
- 每个问题至少 2 个关键数字（结果 + 比较/提升）
- 包含验证说明（"经交叉验证""回测误差 4.1%"）

### 1.6 最后写原则

**Phase 3 第一步不是写摘要，而是：**
1. 先完成全部正文（§1-§7）
2. 从正文提取关键数字和结论
3. 按五要素写摘要初稿
4. 队友互审（至少 1 人检查数值一致性）
5. 润色（禁口语、统一术语）
6. **至少花 2 小时**在摘要上

**为什么最后写：**
- 摘要必须准确反映最终结果（先写会与正文不一致）
- 摘要需要宏观视角（写完正文才有全局观）
- 摘要是评委唯一认真读的部分（值得投入时间）

### 1.7 Few-shot 获奖摘要模板

## 2. 论文标题拟法

- 可用题目原题（如《定日镜场的优化设计》）
- 可微改更"研究化"：《某商超蔬菜类商品动态定价与补货决策研究》《"FAST"主动反射面调节模型》
- 不要用太文艺的标题，要直白点出研究对象+方法

## 3. 七章写作要点

### 一、问题重述
- 背景用自己的话重述 1-2 段（可引用题目数据来源），不照抄原文
- 问题重述：把题目要求改写为清晰的数学问题，逐条列出

### 二、问题分析
- 总体思路：先讲技术路线（数据预处理→相关性→建模→求解→检验→优化）
- **必须配一张总体思路流程图**
- 逐问分析难点与拟用方法

### 三、模型假设
- 4-6 条，编号列表
- 每条必须有事实依据（如"由数据观察，周销量无显著趋势，故假设需求平稳"）
- 假设不合理的直接挂评阅第一原则

### 四、符号说明
- 三列表：符号 / 含义 / 单位，全表列出主要变量

### 五、模型建立与求解（主体，篇幅最大）
- 按 5.1/5.2/5.3/5.4 分问题
- 每问内部固定流程：
  1. **问题分析**（该问难点 + 方法选择理由）
  2. **模型建立**（推导 + 公式连续编号 (1)(2)(3)…）
  3. **模型求解**（算法、参数设置、运行环境）
  4. **结果分析**（结果表 + 图 + 误差分析）
  5. **模型检验**（误差指标、对比实验）
- 数据题必须加**数据预处理/数据侧写**小节（缺失值、异常值、去重、分组聚合）
- 每张图后必须有一句"由图X可看出……"的结论

### 六、模型的评价、改进与推广
- 优点 2-3 条（真实、具体，如"双算法互验，结果可靠"）
- 缺点 2-3 条（诚实，如"未考虑天气因素"）
- 改进与推广（模型可扩展到哪些场景）

### 七、参考文献
- GB/T 7714 格式（见 01-competition-format.md），5-10 条
- 必须是真读过的文献，别抄网上乱写

### 附录
- 代码清单：文件名 / 功能 / 运行环境 列表 + 核心代码全文
- 支撑材料中的代码要与论文附录对应

## 4. 图表规范

- 图：编号 + 题注（"图1 xxx"），正文引用（"如图1所示"），图后带结论
- 表：三线表，编号 + 题注（"表1 xxx"），正文引用（"由表1可知"）
- 结果保留 4 位小数
- 详细示例见 `assets/result-table-samples.md`

## 5. 敏感度分析五步法

**核心原则：敏感度分析要"排名"不要"安慰"。**
"±10% 没变化"被评委鄙视；龙卷风图 + 边界行为 + 结论翻转才是满分。

### 5.1 五步法

| 步骤 | 内容 | 产出 | 评委期望 |
|---|---|---|---|
| 1. 参数排名 | 用 OAT/Sobol/Morris 扫描，按影响力排序 | 龙卷风图（tornado plot） | 知道哪些参数真正在意 |
| 2. 边界行为 | 扫到可行性边界（第5/95百分位），报告什么打破了 | 边界值表 | 知道模型的承受极限 |
| 3. 响应对面 | 对 top-2 参数画 2D 等高线或 1D 响应曲线 | 响应图 | 理解参数如何影响结果 |
| 4. 结论翻转 | 找到至少一个让推荐方案改变的参数区间 | "当 X > 阈值时，方案从 A 变为 B" | 知道推荐的稳健边界 |
| 5. 交互检测 | 如果有 ≥2 个关键参数，检查交互效应 | 交互图/二阶 Sobol | 知道参数是否独立 |

### 5.2 龙卷风图代码模板

```python
import numpy as np
import matplotlib.pyplot as plt

params = ['弹性系数α', '损耗率l', '批发价w', '基线销量q0', '促销系数β']

fig, ax = plt.subplots(figsize=(8, 4))

```

### 5.5 方法选择

| 方法 | 适用场景 | 成本 | 工具 |
|---|---|---|---|
| OAT（一次一参） | 参数独立、模型近似线性 | 低 | 手动 |
| Morris 筛选 | 参数多、快速识别关键参数 | 低 | SALib |
| Sobol 指数 | 需要全局分析、参数有交互 | 高 | SALib |
| 回归分析 | 模型可近似为多项式 | 低 | numpy polyfit |

### 5.6 常见错误（评委扣分点）

| 错误 | 正确做法 |
|---|---|
| "±10% 扰动，结果没变化" | 用龙卷风图排名，扫到边界 |
| 只展示一个参数 | 至少展示 top-5 参数 |
| 扰动幅度太小 | 扫到可行性边界（5th-95th 百分位） |
| 没有结论翻转 | 找到至少一个翻转点 |
| 没有图 | 用龙卷风图 + 响应曲线 |

## 6. 假设闭环协议

### 6.1 假设编号规则

每个假设分配唯一编号：A1, A2, A3, ...

**假设表格式：**

| 编号 | 假设内容 | 理由/来源 | 正文引用 | 敏感度检验 |
|---|---|---|---|---|
| A1 | 日销量近似正态分布 | Shapiro-Wilk p=0.12（>0.05） | §5.1, §6.2 | §7.1 |
| A2 | 品类内损耗率统一 | 附件3 无单品级数据 | §5.3 | §7.2 |
| A3 | 价格弹性在预测范围内恒定 | 线性回归 R²=0.87 | §5.2 | §7.1 |

### 6.2 闭环流程

```
假设声明（§3 假设表）
    ↓
正文引用（§5 中写 "基于假设 A2..."）
    ↓
结论回溯（§6 中写 "本结论依赖于假设 A1 和 A3"）
    ↓
敏感度检验（§7 中检验 A1/A3 的影响）
```

### 6.3 假设质量检查清单

| 检查项 | 好假设 | 差假设 |
|---|---|---|
| 具体性 | "日销量服从正态分布（Shapiro-Wilk p=0.12）" | "数据是可靠的" |
| 可检验 | 能用数据验证或敏感度分析检验 | 无法验证 |
| 有理由 | "基于文献[X]的实证研究" | "为了简化" |
| 有影响 | 明确说明如果假设不成立会怎样 | 不讨论后果 |
| 编号引用 | 正文中引用 "基于 A2" | 正文不引用假设 |
| 敏感度检验 | §7 中检验该假设的影响 | 不检验 |

### 6.4 假设撰写模板

```
A1: [假设内容]
    理由: [数据证据/文献支持/合理推断]
    影响: 如果不成立，则 [具体后果]
    引用: 本文 §[X] 基于此假设
    检验: §[Y] 敏感度分析检验此假设
```

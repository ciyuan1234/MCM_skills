# 06 · 检查清单（阶段自检 + 交卷前核对）

## 1. 阶段自检（每个 Phase 结束时过一遍）

### Phase 1 数据探索完成后
- [ ] 每个附件都打开确认了字段含义
- [ ] 缺失值/异常值/重复值已处理并记录方法
- [ ] 数据侧写（均值/分布/时序图）已产出
- [ ] 发现的问题（如某品类销量为零）已记录到进度日志
- [ ] 已运行 `make-data-contract.py` 生成 `1_数据/data_contract.json`

### Phase 2 每个问题求解完成后
- [ ] 模型能解释"为什么选它"
- [ ] 公式编号连续、变量与符号说明表一致
- [ ] 有误差分析（MAE/RMSE/MRE/R² 等）
- [ ] 有灵敏度/稳定性分析
- [ ] 结果保存为 xlsx/mat，数值与论文一致
- [ ] 代码可运行、有注释、UTF-8 编码
- [ ] 代码确实读取了数据文件（无硬编码数值）
- [ ] 绘图脚本有 `# 数据来源` 与 `# 对象数` 声明，图元素数 == 数据对象数

### Phase 3 每章写完后
- [ ] 摘要逐问覆盖 + 每个问题有数值结果
- [ ] 图有编号题注、正文有引用
- [ ] 表为三线表、有编号题注
- [ ] 参考文献 GB/T 7714、无编造文献

## 2. 交卷前核对（最后 3 小时逐条打勾）

### 格式
- [ ] 摘要独占一页，无队号姓名
- [ ] 正文字号：小四宋体，标题黑体
- [ ] 公式居中、编号右对齐、连续
- [ ] 页面 A4，页码正确
- [ ] 附录代码清单齐全

### 内容
- [ ] 摘要五要素齐全（归类/思想/算法/特点/结果）
- [ ] 每个问题的结果都在摘要中出现具体数值
- [ ] 灵敏度分析每个模型都有
- [ ] 图表每张都有编号+题注+正文引用
- [ ] 模型假设有依据、不随意
- [ ] 参考文献 5-10 条、格式正确

### 数据与代码一致性（最容易翻车）
- [ ] 论文里的每个数值都能在 2_代码 运行结果中找到出处
- [ ] 支撑材料里的代码 == 论文中引用的代码
- [ ] 代码在干净环境能跑通（重跑一遍主程序）
- [ ] 题目要求的输出文件（如 result.xlsx）命名与要求完全一致
- [ ] 已运行 `verify.py .`，错误项全部修复、警告已处理
- [ ] 图表三方对应：论文"图N" ↔ 3_图表 文件 ↔ 绘图代码 savefig
- [ ] 每张图元素数量与数据对象数一致（3 组数据 3 条线/3 根柱）
- [ ] 摘要关键数值能在运行结果/数据契约中找到出处

### 查重
- [ ] 摘要/正文用自己的话重写，无大段复制
- [ ] 图表用自己数据重画
- [ ] 全篇通读一遍，中文表述通顺

### 提交物
- [ ] 论文 PDF（最终版）已导出
- [ ] 支撑材料 zip（代码+数据+说明）已用 package.ps1/sh 打包
- [ ] 按题目要求上传的文件命名正确
- [ ] 在截止前至少 30 分钟完成提交（留上传缓冲）

## 3. 用 checks.py 自动检查

在比赛工作目录运行：
```
python cumcm/scripts/checks.py 4_论文/paper.md .
```
它能自动检查：结构完整性、摘要字数/五要素/数值密度、图/表/公式编号连续性、
参考文献、提交物完整性。**自动检查不能替代人工核对本清单。**

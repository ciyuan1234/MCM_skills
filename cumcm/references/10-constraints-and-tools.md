# 10. 防幻觉约束全清单与工具用法

> 本文件把"数据·代码·图表三方溯源协议"展开为可执行细则，并给出工具用法与正反判例。
> 核心问题：**如何保证"代码计算的结果依据真实数据形成"、"图与数据一致（3 组画 3 条）"？**
> 答案：软约束（红线）+ 硬校验（verify.py 自动拦截）+ 工具链（导出/绘图模板）三层。

## 一、三类约束体系

| 层级 | 机制 | 靠什么执行 |
|---|---|---|
| 软约束 | SKILL.md 红线 1-8 | AI 自觉（指令层） |
| 硬校验 | data_contract.json + verify.py | 工具拦截（脚本层） |
| 工具链 | plot-style.py / export-paper.ps1 | 自动化（脚本层） |

## 二、数据契约（data contract）

**什么时候生成**：Phase 1 处理完附件后立即执行
```
python scripts/make-data-contract.py 1_数据
```
**契约里有什么**：每个数据文件的 sha256、行数/列数、字段名、数值列统计量（sum/mean/max/min/count）。
**为什么能防幻觉**：代码若真的读取该文件，运行结果必然与契约统计量一致；
论文数值若既不在契约里、也不在代码输出里 → 必是编造。

**硬编码反例**（verify.py 会警告"疑似硬编码"）：
```python
# 错误：数值直接写死在代码里，没有读取任何数据文件
sales = [0.5, 0.48, 0.42, 0.39]   # 这些数哪来的？无法验证
```
```python
# 正确：数据来自文件，代码可复现
import pandas as pd
df = pd.read_csv("1_数据/附件.csv")
sales = df.groupby("品类")["销量"].mean().tolist()
```

## 三、图表与数据一致性（最易被评委识破的扣分点）

**硬规则（违反即失败）**：
1. 绘图脚本文件头必须写两行注释：
   ```
   # 数据来源: 1_数据/data_contract.json
   # 对象数: 3
   ```
2. 图中柱/线/点系列数量 == 数据对象数（`# 对象数` 必须等于真实分组数）
3. 图例必须来自数据列名 / 分组标签，禁止手写与数据无关的图例
4. 论文"图N" 与 `3_图表/` 图片文件一一对应，且图片由绘图代码的 savefig 输出

**正例**：3 个品类 → 柱状图恰好 3 根柱，图例为数据列名，保存为 `fig1_品类销量.png`
**反例（违规）**：数据有 3 个品类，代码只画 2 条线（或图例写"方案1/方案2"与数据无关）
**反例（违规）**：论文出现图 5，但 3_图表 只有 4 张图

## 四、数值溯源

**规则**：论文摘要与正文中的每个关键数值，必须能在以下至少一处找到：
- 代码输出文件（`2_代码/**/results*.csv`、运行日志、*.out）
- 数据契约 stats

**做法**：结果一律由代码写入 `results.csv` / 运行日志，论文直接引用这些数值，
**禁止手改**（红线 4）。写作时保持"论文数值 ↔ 输出文件 ↔ 契约统计量"三向一致。

## 五、工具用法速查

```bash
# 1) Phase 1 数据契约
python scripts/make-data-contract.py 1_数据

# 2) Phase 2/4 溯源硬校验（提交前必须全绿）
python scripts/verify.py .

# 3) Phase 4 论文格式检查
python scripts/checks.py 4_论文/paper.md .

# 4) Phase 4 导出 PDF（Word 路线，无需 LaTeX）
.\scripts\export-paper.ps1 -WorkDir .

# 5) 打包支撑材料
.\scripts\package.ps1
```

## 六、verify.py 检查项速查

| 检查项 | 判定 | 级别 |
|---|---|---|
| data_contract.json 是否存在 | Phase 1 强制产物 | 错误 |
| 脚本是否含读取数据语句 | 全是数字字面量且无读取 → 疑似硬编码 | 警告 |
| 论文图N ↔ 3_图表 文件数 | 引用超过文件数 | 错误 |
| 绘图脚本是否有 `# 数据来源` 声明 | 缺 → 警告 | 警告 |
| 绘图对象数 vs 数据列数 | 声明对象数 < 数据分组数 | 错误 |
| 摘要数值能否在输出/契约中找到出处 | 缺出处 → 警告 | 警告 |
| 论文引用的代码文件是否存在 | 不存在 | 错误 |

## 七、常见反例速记（评卷视角）

- ❌ 代码运行报错，结果靠"手算/手写"填进论文 → 禁止，结果必须可复现
- ❌ 柱状图 3 个对象画 2 条线 → `# 对象数` 声明与数据不一致
- ❌ 摘要写"准确率 98.2%"，任何文件里都搜不到 98.2 → 数值无出处
- ❌ 图注写的图 4，3_图表 里根本没有第 4 张图 → 三方对应断裂
- ✅ 每个数字都能指向：附件文件 → 代码读取 → 输出文件 → 论文引用

# 获奖论文基准（篇幅/字数/公式/图表密度）

> 来源：本地资料库 `2.历年国赛获奖论文（1992-2023）` 可提取文本的论文 +
> 中国大学生在线官方论文展示页（网络）。用于校准检查器阈值与论文写作目标。
> 统计口径：正文 = 摘要页后至参考文献/附录标题前；附录 = 参考文献后（含代码）。

## 2. 结论（阈值依据）

| 指标 | 获奖论文实测 | 检查器阈值（v1.4.0） |
|---|---|---|
| 正文页数 | 25-35 页 | HARD 上限 30（官方）；目标 15-25；<12 页 WARN |
| 附录页数 | 19-38 页（代码全量） | 不计入正文；要求含文件列表+完整代码 |
| 摘要字数 | 914-1097 字 | 700-1300 PASS（<500 ERR / 500-699 WARN） |
| 公式编号 | 42-77 处 | <10 处 WARN |
| 图数量 | 30-34 张 | 图+表 <8 个 WARN |
| 表数量 | 11-25 张 | （同上合并） |
| 参考文献 | — | 5-10 条建议 |

## 3. 使用方式

- 写作阶段：论文模板（paper-template.md）按"每问五段式 + 数据预处理 + 灵敏度 + 方案对比"结构
  产出，目标正文 15-25 页（不必追满 30，但低于 12 页会被检查器提示）
- 检查阶段：checks.py 第 5.5 节后新增篇幅/密度检查，format-check.py 页数下限提示
- 篇幅本质：页数不是目的，是"分析深度"的外显——每问都有完整模型链
  （分析→假设→符号→目标/约束→算法→求解→结果分析→检验）自然会到 15+ 页

## 4. 扫描件说明

2021C-066 / 2022C-065 为扫描 PDF（无文本层），仅页数可参考；
2023C-050 与 C235 为有文本层论文，统计可靠。
